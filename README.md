# 🩺 Para Alejita · 14 de Abril

Un tomo artesanal y afectivo concebido como homenaje personal para Alejita.
Combina la encuadernación en **cuero vino repujado en oro rosa**, motivos de medicina, salud, afecto incondicional y recuerdos desde el colegio.

---

## ✨ Características Especiales

* 📖 **Animación Física de Libro 3D:** Hojas con curvatura, texturas de pergamino y sombras realistas mediante `PageFlip`.
* 🔐 **Privacidad Estricta & PIN de Acceso:** 
  - La persona debe ingresar el código personal `1404` (14 de Abril) para abrir las páginas.
  - Soporta enlace de desbloqueo directo mediante token: `?key=1404`.
  - Etiquetas `noindex, nofollow` para evitar indexación en motores de búsqueda.
* 💓 **Fondo Animado de Latidos & Corazones:** Canvas con motas de luz sanadora y corazoncitos ascendentes.
* 💌 **Cartica Recreada desde Cero:**
  - Letra capitular iluminada `H` con estetoscopio y amigas.
  - Línea de electrocardiograma (ECG) animada que late en tiempo real.
  - Cita destacada: *«Tu felicidad es la mía»*.
  - Texto completo de complicidad y agradecimiento desde el colegio.
  - Botón interactivo para explorar la cartica original en Lightbox HD.
* 🎂 **Capítulo I · Cumpleaños:** Portadilla y espacio reservado para la carta de cumpleaños de este año.
* 🎄 **Capítulo III · Navidad:** Interfaz cálida lista con lazos rojos, acebo y marco para el futuro mensaje navideño.
* 🍇 **Capítulo IV · Fin de Año:** Interfaz ambientada con las doce uvas doradas y deseos de salud y alegría.
* 📡 **Telemetría Aislada:** Registra lectura en Firebase bajo `sessions_aleja`.
